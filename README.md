# Silicon Valley Archives
Github page of the Silicon Valley Archives at Stanford University Libraries

## Zotero Library
A shared Zotero [library](https://www.zotero.org/groups/6129122/silicon_valley_archives_collections__shared_bibliography/library) that includes all SVA collections, along with many related Stanford collections and a working Silicon Valley bibliography.

## Collections Narrative
A recent narrative [overview](https://docs.google.com/document/d/11T6M6rDP6qcpex83EOdHti4AI_AHpfiUa6rRnzAs2qQ/edit?tab=t.0) that covers the history of the archive and collection strengths.

## Accessing Special Collections
All physical collections in the Silicon Valley Archives are accessed through the standard Green Library Special Collections reading room. More information about Special Collections and access procedures is available [here](https://library.stanford.edu/libraries/special-collections).

## Catalog Search
Many though not all Silicon Valley Archives collections can be found via this [search](https://searchworks.stanford.edu/?search_field=search&q=%22silicon+valley+archives%22) of the Stanford catalog.
