# Silicon Valley Archives: A Collections Explorer

The source of the collections explorer at
https://silicon-valley-archives.github.io/sva-collections-explorer/ — an annotated bibliography and
timeline of almost 2,000 Stanford collections that may be relevant to the study of Silicon Valley.

For the Silicon Valley Archives at Stanford University Libraries, see
[github.com/silicon-valley-archives](https://github.com/silicon-valley-archives).
